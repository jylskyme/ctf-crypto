Web 攻击速查

漏洞类型 → 利用

SQL注入 → union/盲注/报错/堆叠
XSS → 反射/存储/DOM
文件上传 → 绕过后缀/MIME/内容检测
SSRF → 内网探测/gopher/伪协议
命令注入 → 管道符/反引号/$()绕过
反序列化 → POP链/魔术方法
SSTI → 模板引擎沙箱逃逸

Pwn 攻击决策树

漏洞 → 利用方法

栈溢出 → ret2text/ret2shellcode/ROP
格式化字符串 → 泄露/任意写
堆溢出 → unlink/fastbin/tcache
UAF → double free/tcache poisoning
整数溢出 → 绕过长度检查
off-by-one → 修改chunk size/fd
保护机制 → canary/PIE/NX/RELRO

逆向分析流程

步骤

1.查壳 → PEiD/DIE/ExeinfoPE
2.静态 → IDA/Ghidra反编译
3.动态 → x64dbg/gdb跟踪
4.算法 → 识别加密逻辑
5.脱壳 → ESP定律/手动跟踪
6.Patch → 修改跳转/NOP

RSA 攻击决策树

已知参数 → 攻击方法

n小(<100位) → factordb/yafu分解
e=3,无padding,短明文 → 直接开立方根
同n不同e,gcd=1 → 共模攻击
e=3,≥3个不同n → 广播攻击(CRT)
e很高(≈n位数) → Wiener's Attack
已知明文高位 → Coppersmith
dp泄露 → 枚举gcd得p
|p-q|很小 → Fermat分解

核心公式

数论 & RSA

ext_gcd: ax+by=gcd(a,b) mod_inv: a^(-1) mod n [gcd(a,n)=1] Fermat: a^(p-1)≡1 (mod p) Euler: a^φ(n)≡1 (mod n) CRT: x≡ai (mod ni), ni互素 φ(pq)=(p-1)(q-1) RSA: c=m^e mod n, m=c^d mod n
